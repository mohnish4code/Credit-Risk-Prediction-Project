💳 Credit Risk Prediction ML Project
📌 Problem Statement

This project aims to predict whether a customer will default on a loan based on financial and personal attributes.

🎯 Objective

To build an end-to-end Machine Learning pipeline that can classify loan applicants as risky or safe.


⚙️ Tech Stack
Python
Pandas, NumPy
Scikit-learn
Matplotlib, Seaborn
Streamlit (for UI)

🔄 Workflow
Data Collection
Data Cleaning & Preprocessing
Feature Engineering
Model Training
Model Evaluation
Prediction

📊 EDA Insights
Dataset contains both numerical and categorical features
Some features had missing values handled using median/mode
Target variable is slightly imbalanced


📌 Future Improvements
Hyperparameter tuning
Model explainability (SHAP)
Deployment on cloud
